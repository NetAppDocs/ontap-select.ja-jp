= ONTAP Select環境のセキュリティを確保
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
コマンドラインインターフェイスを使用して、必要に応じて Deploy 仮想マシンの管理者アカウントのパスワードを変更することで、ONTAP Select の展開環境をセキュリティで保護できます。

.手順
. 管理者アカウントを使用して、 Deploy ユーティリティの CLI にサインインします。
. パスワードを変更します :'password modify
. 環境に応じて、すべてのプロンプトに応答します。
