[role="lead"]
Deploy管理ユーティリティをハイパーバイザー環境にインストールする前に、必要な設定情報とオプションのネットワーク設定情報を確認して、導入の準備をします。



[[required-configuration-information]]
== 必要な設定情報

導入計画の一環として、 ONTAP Select Deploy 管理ユーティリティをインストールする前に、必要な設定情報を特定しておく必要があります。

[cols="40,60"]
|===
| 必要な情報 | 説明 


| Deploy仮想マシン（VM）の名前 | VMに使用する識別子。 


| ハイパーバイザーホストの名前 | DeployユーティリティがインストールされているVMware ESXi、Hyper-V、またはKVMハイパーバイザーホストの識別子。 


| 保管場所の名前 | VMファイルが格納されているデータストア（ESXi）またはストレージプール（Hyper-VまたはKVM）の識別子（約40GBの容量が必要です）。 


| VMのネットワーク | Deploy VMが接続されているネットワークの識別子。 
|===


[[optional-network-configuration-information]]
== オプションのネットワーク構成情報

デプロイ用VMは、デフォルトではDHCPを使用して構成されます。ただし、必要に応じて、VMのネットワークインターフェースを手動で設定することもできます。

[cols="35,65"]
|===
| ネットワーク情報 | 説明 


| ホスト名 | ホスト・マシンの識別子 


| ホストの IP アドレス | ホストマシンの静的 IPv4 アドレス。 


| サブネットマスク | VMが属するネットワークに基づいたサブネットワークマスク。 


| ゲートウェイ | デフォルトゲートウェイまたはルータ。 


| プライマリ DNS サーバ | プライマリドメインネームサーバ。 


| セカンダリ DNS サーバ | セカンダリドメインネームサーバ。 


| 検索ドメイン | 使用する検索ドメインのリスト。 
|===
